# JSON Schemas

## Agent Context Envelope v1



**Schema ID**: `https://frootai.dev/schemas/agent-context-envelope.v1.json`

  "properties": {
    "$schema": { "type": "string", "format": "uri" },
    "schema_version": { "const": "1.0.0" },
    "applicability": { "enum": ["applicable", "not_applicable"] },
    "reason": { "type": "string", "minLength": 10 },
    "envelope": {
      "type": "object",
      "additionalProperties": false,
      "required": ["context_id", "trace_id", "created_at", "classification", "provenance", "freshness", "token_budget", "compaction", "injection_boundaries", "references"],
      "properties": {
        "context_id": { "type": "string", "minLength": 1 },
        "trace_id": { "type": "string", "minLength": 1 },
        "created_at": { "type": "string", "format": "date-time" },
        "classification": { "enum": ["public", "internal", "confidential", "restricted"] },
        "provenance": {
          "type": "array",
          "minItems": 1,
          "items": {
            "type": "object",
            "additionalProperties": false,
            "required": ["source", "retrieved_at"],
            "properties": {
              "source": { "type": "string", "minLength": 1 },
              "retrieved_at": { "type": "string", "format": "date-time" },
              "sha256": { "$ref": "#/$defs/sha256" }
            }
          }
        },
        "freshness": {
          "type": "object",
          "additionalProperties": false,
          "required": ["max_age_seconds", "stale_behavior"],
          "properties": {
            "max_age_seconds": { "type": "integer", "minimum": 0 },
            "stale_behavior": { "enum": ["reject", "refresh", "warn"] }

        },
        "token_budget": {
          "type": "object",
          "additionalProperties": false,
          "required": ["maximum", "reserved_for_output"],
          "properties": {
            "maximum": { "type": "integer", "minimum": 1 },

        "compaction": {
          "type": "object",

              "uri": { "type": "string", "format": "uri-reference" },

              "immutable": { "const": true }
            }
          }
        },
        "payload": { "type": "object" }
      }
    }
  },
  "allOf": [
    { "if": { "properties": { "applicability": { "const": "applicable" } } }, "then": { "properties": { "envelope": {} }, "required": ["envelope"] } },
    { "if": { "properties": { "applicability": { "const": "not_applicable" } } }, "then": { "properties": { "reason": {}, "envelope": false }, "required": ["reason"] } }

The 13 overlay domains (regions, models, skus, naming, tags, network, rbac, identity, iac, encryption, observability, cost, custom_checks) compose across resolver -> composer -> emitter pipelines. Every overlay is OPTIONAL — an absent domain contributes no overlay for that slice; an empty array means 'no constraint' (NOT 'reject everything'). NEVER FAKE A SIGNAL §0.5 #4: the schema only describes shape; semantic enforcement lives in the V7.4-V7.18 overlay functions and surfaces typed PolicyError on conflict.
