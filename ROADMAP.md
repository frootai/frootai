## The mission, in one paragraph

FrootAI is building the **open substrate of the agentic AI economy** — the FAI Protocol that wires fragmented primitives (agents, instructions, skills, hooks, workflows, plugins, tools, prompts, guardrails) into deterministic, evaluated, governed AI solutions. MCP solves tool-calling. AG-UI solves rendering. **FAI Protocol solves context-wiring + determinism + governance.** Our open core stays MIT forever; we earn revenue on hosted runtime, evaluation, governance, and the marketplace.

## What we will **not** build

These are deliberate non-goals — we wire what others build, not duplicate them:

- ❌ **Our own foundation model** — we route to OpenAI, Anthropic, Mistral, open models, and customer-provided.
- ❌ **Our own AI IDE** — we publish rule packs for Cursor / Windsurf / Continue / Cline / VS Code / JetBrains / Aider / Claude Code.
- ❌ **Our own framework** — we wire LangChain, LlamaIndex, CrewAI, AutoGen, Semantic Kernel, Microsoft Agent Framework, etc.
- ❌ **Our own vector DB** — we plug into Pinecone, Weaviate, Qdrant, Milvus, pgvector, Azure AI Search, Vespa, Turbopuffer.
- ❌ **A closed-source pivot.** The protocol and open core stay MIT forever. No bait-and-switch.

## How decisions are made

See [`GOVERNANCE.md`](./GOVERNANCE.md). In short:
- **Routine changes** → lazy consensus (1 maintainer approval).
- **Significant changes** → 2 maintainer approvals + 7-day comment window.
- **Strategic changes (protocol, license, repo splits)** → RFC + 14-day public comment.

## The non-negotiables

These remain true through every phase:

1. The protocol stays **MIT**. Forever.
2. The brand stays **warm, opinionated, open, deep, deterministic, frootful, honest, kind**.
3. Customer data is **never** sold or used to train models without explicit, granular, revocable opt-in.
4. We **never fake metrics** — no bought stars, no padded MAUs.
5. We are **framework-neutral** — we wire LangChain, CrewAI, SK, AutoGen, all of them; we don't compete with them.
6. We **never silently break a public API** — 90-day deprecation notice always.
7. We **show our work** — public retrospectives, honest changelogs, including misses.
