# FrootAI Support

Use the channel that best matches the request so it reaches the appropriate maintainers.

## Support channels

| What you need | Where to go |
|---------------|-------------|
| **Bug report** (something is broken) | [Bug report](https://github.com/frootai/frootai/issues/new?template=bug-report.yml) |
| **Feature request** (you wish FrootAI did X) | [Feature request](https://github.com/frootai/frootai/issues/new?template=feature-request.yml) |
| **Question** ("how do I...?") | [Documentation](https://frootai.dev/docs) or [Agent FAI](https://frootai.dev/chatbot) |
| **Real-time docs lookup** | [Agent FAI chatbot](https://frootai.dev/chatbot) |
| **Security vulnerability** | [Security Policy](./SECURITY.md) — **never** open a public issue |
| **Code of Conduct concern** | conduct@frootai.dev |
| **Enterprise / commercial** | info@frootai.dev |

## Filing an actionable bug report

A great bug report tells us:

```markdown
**Channel + version**:
e.g. `frootai-mcp@6.1.1` (npm) on macOS 14, Node 22.

**What you expected to happen**:
e.g. the MCP server should expose its documented tools after startup.

**What actually happened**:
e.g. the client connected, but tool discovery returned an empty result.

**Reproduction steps**:
1. ...
2. ...
3. ...

**Logs / output**:
```
paste relevant output here, redact secrets
```

**Environment**:
- OS:
- Node / Python version:
- Other relevant info:
```

The faster we can reproduce, the faster we can fix.

## Response targets

Targets are measured from receipt and may vary with severity, reproducibility, and maintainer availability.

| Channel | Typical First Response |
|---------|-----------------------|
| Security report | ≤3 business days (see [SECURITY.md](./SECURITY.md)) |
| Critical bug (broken release, data loss) | ≤2 business days |
| Regular bug | Within a week |
| Feature request | Reviewed in monthly triage |
| Q&A discussion | Community and maintainer best effort |
| Agent FAI chatbot | Instant (24×7) |

If you have not heard back after the typical window, **do not open a duplicate
issue** — instead, leave a polite comment on the existing thread bumping it.

## Communication standards

- Be specific. "It doesn't work" is not actionable.
- Be patient. Maintainers volunteer their time.
- Be kind. Read [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md).
- Be helpful. If you find an answer, share it back.
