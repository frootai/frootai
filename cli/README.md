# FrootAI CLI

The supported CLI is distributed as the [`frootai` npm package](https://www.npmjs.com/package/frootai).

This public repository documents the FAI Protocol and hosts community content. CLI implementation, authentication, update, signing, and release logic are maintained through controlled private engineering and release systems.

## Run

```text
npx -y frootai --help
```

See the [CLI setup guide](https://frootai.dev/setup-guide#cli) and [public repository scope](../REPOSITORY_SCOPE.md).

Historical source remains available in prior Git revisions for license and provenance purposes. This directory is not a build or release authority.
