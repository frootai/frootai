# harvest-defaults — deterministic cookbook copies for the harvest pipeline

**[H0.16]** Baseline files copied verbatim (or template-substituted) by the
repo-to-Solution-Play harvest pipeline when a slot is marked `deterministic
cookbook copy` in the 40-file Reference Solution Play anatomy.

## Files and where they land in an emitted play

| Source (this folder)         | Lands at (in emitted play)              | 40-file ref | Confidence | Notes |
|------------------------------|------------------------------------------|-------------|------------|-------|
| `security.instructions.md`   | `.github/instructions/security.instructions.md` | 18 | 1.0 | Copied verbatim (cloud-agnostic OWASP LLM Top 10) |
| `guardrails.json`            | `.github/hooks/guardrails.json`          | 15          | 1.0        | Copied with `{play_name}` and `{agents_line}` token substitution |
| `mcp.json`                   | `.vscode/mcp.json`                        | 28          | 1.0        | Baseline (FAI MCP only); pipeline appends detected upstream MCP servers |
| `settings.json`              | `.vscode/settings.json`                   | 29          | 1.0        | Copied verbatim; pipeline may merge language-specific keys |
| `copilot-instructions.md`    | `.github/copilot-instructions.md`         | 11          | (skeleton)  | Skeleton/fallback. File 11 is normally S5 (LLM); this is the cookbook fallback used when the LLM step fails or when `--no-llm` is set. |
| `.gitignore`                 | (root of emitted play)                    | —           | 1.0        | Multi-stack baseline: Python, Node, .env, Terraform state, IDE cruft. Pipeline appends play-specific patterns. |

## Token substitution

A small set of `{token}` placeholders may appear in these files. The harvest
pipeline (`[H5]` scaffolder) is responsible for substitution at copy time:

| Token            | Substituted with                                       | Source                                  |
|------------------|--------------------------------------------------------|-----------------------------------------|
| `{play_name}`    | Human-readable play title (e.g. `Enterprise RAG`)      | `RepoFacts.title`                       |
| `{play_slug}`    | kebab-case slug (e.g. `enterprise-rag`)                | `RepoFacts.slug`                        |
| `{primary_cloud}`| `azure` / `aws` / `gcp` / `multi`                      | `[H0.6]` primary-cloud detector         |
| `{agents_line}`  | One-line agent roster (e.g. `@builder @reviewer ...`)  | `RepoFacts.agents[].name` join          |

Files with no tokens are copied byte-for-byte.

## Doctrine

- **No cloud-specific examples** in these defaults — cloud-specific guidance
  is generated by S5 (LLM) into the `<cloud>-coding.instructions.md` and
  `<domain>-patterns.instructions.md` files (rows 16-17 of the 40-file shape).
- **No service-specific values** — pricing thresholds, region pins, model
  names belong in `config/openai.json` (or sibling), generated from
  `RepoFacts` deterministically.
- **Edits must preserve cloud-neutrality** — if a contributor adds an Azure-
  only or AWS-only example here, [H0.12] fact-check WILL reject the emitted
  play if the literal isn't in `RepoFacts`. Keep this folder clean.
