# Official Azure Architecture Icons

These SVG files are copied unmodified from Microsoft Azure Architecture Icons V24 for architecture diagrams and solution documentation.

Source: https://learn.microsoft.com/azure/architecture/icons/

Microsoft permits these icons in architecture diagrams, training materials, and documentation. Do not crop, rotate, recolor, distort, or use them to represent a non-Microsoft product.
