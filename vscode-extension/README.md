# FrootAI for VS Code

The supported FrootAI extension is distributed through the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=frootai.frootai-vscode).

This public repository contains the FAI Protocol, Solution Plays, community primitives, schemas, and documentation. The extension implementation and release system are maintained in a controlled private engineering repository.

## Install

```text
code --install-extension frootai.frootai-vscode
```

See the [VS Code setup guide](https://frootai.dev/setup-guide#vscode) and [public repository scope](../REPOSITORY_SCOPE.md).

Historical source remains available in prior Git revisions for license and provenance purposes. This directory is not a build or release authority.
